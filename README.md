# 1. What is SkillSwap?

SkillSwap is a lightweight marketplace that connects **creators who offer skills** with **clients looking for services**.

A creator can publish a gig with a title, category, price and description. Clients can discover available gigs, search by keyword or category, submit booking requests and track their booking status.

The product is designed around a simple flow:

```text
Creator
   │
   ▼
Post a Gig
   │
   ▼
Marketplace
   │
   ├── Search
   ├── Category Filter
   └── Browse Gigs
          │
          ▼
       Book Gig
          │
          ▼
       Pending
          │
          ▼
   Creator Dashboard
       /       \
      /         \
 Accept        Decline
   │              │
   ▼              ▼
Accepted       Declined
